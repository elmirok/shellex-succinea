# Succinea

Succinea is a small host status bar app. Right-click it to edit visible status modules. When W3 desktops are enabled, Succinea can show compact desktop buttons so the user can switch desktop by clicking 1, 2, 3 or 4.

Run `succinea help` in Shell for usage.

Configuration lives at `/system/succinea/config.json` inside the vault.

## Shellex package

- App id: `system.succinea.local`
- Version: `1.0.2`
- Runtime: `host`
- Type: `system-app`
