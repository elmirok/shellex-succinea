# Succinea

Succinea is a small host status bar app. Right-click it to edit visible status modules.

Run `succinea help` in Shell for usage.

Configuration lives at `/system/succinea/config.json` inside the vault.

## Shellex package

- App id: `system.succinea.local`
- Version: `1.0.0`
- Runtime: `host`
- Type: `system-app`
